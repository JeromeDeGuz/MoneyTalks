# MoneyTalks – Iteration 1

## 1.  What’s This Iteration About
This is the first full feature version after we made our vision statement simpler and less techy. Everything else is the same, just described better to match expectations.  

---

## 2.  What Works Now

### 2.1 Adding Expenses
- Users can add a new expense.  
- Can enter: name, amount, date, optional note, category (from a preset list).  
- Expense ID is handled automatically.

### 2.2 Viewing Expenses
- All added expenses show up in a neat list.  
- Shows name, amount, date, note (if any), and category.

### 2.3 Easy Controls
- Click the plus (+) button to add an expense.  
- If you go to add by mistake, hit Cancel to go back.  
- Delete expenses directly from the list if added by mistake.

## 4. Validation & Testing
- Can’t add invalid data like empty names or negative amounts.  
- JUnit tests cover adding, viewing, and deleting expenses.

## 5. How to Use
- Open in Android Studio.  
- Run on emulator or device.  
- Add expenses with the plus (+) button. Cancel or delete if needed.
